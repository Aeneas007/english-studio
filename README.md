## 离线与数据

首次打开需联网。页面、打开过的正文和查过的词库分片会缓存；书籍详情可提前下载正文与相关词库。TTS 能否离线取决于设备语音包。在线翻译需要网络，可能限额或翻译不准确。

浏览器存储空间有限，清理浏览器数据或换手机不会自动同步。请在“我的学习”导出备份。导入备份会合并读物、生词、笔记、进度、译文与统计，并恢复阅读偏好；不会自动开启外部翻译。新概念的本站原创配套可直接使用；原版教材及原版音频需另行准备，PDF 暂不直接解析。输出草稿随全部备份保存。

## 来源与范围

English Studio 专注于阅读、听力与词汇积累，采用本地保存、无需账号的学习方式。功能现状、验证记录和后续方向见 [项目现状与未来计划](docs/roadmap.md)。当前朗读使用设备语音，原著级别为学习建议，非分级改写。

- 圣经：见 [bible/SOURCE.md](bible/SOURCE.md)。
- 短篇、情境课程和界面为独立原创。

## 开发与验证

纯静态 HTML / CSS / ES modules，无构建依赖。使用任意支持 `.mjs` MIME 的静态 HTTP 服务器预览；Service Worker 需要 localhost 或 HTTPS。GitHub Pages 使用 `main / (root)`。

```sh
node --test
```

本轮在连接的 Android 真机验证了点词保存、听读时查词暂停及关闭恢复、横滑翻页；在浏览器完成了 5 词、10 题的配对与释义练习。这些检查不代表全部设备兼容性或声音质量验收，后台播放和更多设备仍需继续验证。
