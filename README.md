# English Studio 4.0

手机使用：[打开 English Studio](https://aeneas007.github.io/english-studio/)。无需账号，学习记录保存在当前浏览器。手机浏览器可以添加到主屏幕。

## 这一版

- 重做书架与沉浸阅读器：搜索、级别、收藏、续读、章节、分页、字号、行距和三种主题。
- 759,374 条 ECDICT 英汉词条，音标、英文释义、常见词形和原形查询。按分片加载，查过的词库离线缓存。
- 点词查义、首尾点选短语、整句翻译、双语阅读、书签和笔记。可选 MyMemory 在线翻译，默认关闭，开启后仅发送请求翻译的文本，结果缓存在本地。
- 设备英语 TTS：逐句听读、设备支持时逐词高亮、从指定句播放、暂停、速度/声音、自动下一章及睡眠定时。
- 单词本保存原文例句与来源，可跳回原文；释义选择、听音辨词和拼写复习，根据反馈安排下次复习。
- 6 篇原创分级短篇；《爱丽丝梦游仙境》《金银岛》《秘密花园》3 本完整英文原著、共 73 章。
- KJV 英文圣经 66 卷 / 1,189 章 / 31,102 节，按卷加载。
- 新概念 1–4 册入口，可导入自己的 TXT / 未加密 EPUB；Lesson 标题自动分课。文件在浏览器内解析，不上传。
- 4 个原创生活场景课程、24 句表达，包含理解、听力与拼句练习。
- 本地学习统计、JSON 全部备份与合并恢复、单词 CSV 导出、可恢复的本地书籍移除。
- 自动迁移旧版进度、收藏、单词和导入读物；保留旧版存储键以便恢复。

## 离线与数据

首次打开需联网。页面、打开过的正文和查过的词库分片会缓存；书籍详情可提前下载正文与相关词库。TTS 能否离线取决于设备语音包。在线翻译需要网络，可能限额或翻译不准确。

浏览器存储空间有限，清理浏览器数据或换手机不会自动同步。请在“我的学习”导出备份。导入备份会合并读物、生词、笔记、进度、译文与统计，并恢复阅读偏好；不会自动开启外部翻译。新概念教材及原版音频不内置，PDF 暂不直接解析。

## 来源与范围

这是独立实现的学习工具，与 EWA 无关联。功能对照、验证记录和仍存在的差距见 [docs/ewa-comparison.md](docs/ewa-comparison.md)。没有 EWA 授权影视、课程或真人有声书资源，没有账号、支付或服务端推荐。原著级别为学习建议，非分级改写。

- 词典：[ECDICT](https://github.com/skywind3000/ECDICT)，MIT 许可，见 [lexicon/LICENSE.txt](lexicon/LICENSE.txt)。
- 原著：[Project Gutenberg](https://www.gutenberg.org/)，原文件及完整许可保存在 [content/sources](content/sources)，见 [内容来源](content/SOURCE.md)。
- 圣经：见 [bible/SOURCE.md](bible/SOURCE.md)。
- 短篇、情境课程和界面为独立原创。

## 开发与验证

纯静态 HTML / CSS / ES modules，无构建依赖。使用任意支持 `.mjs` MIME 的静态 HTTP 服务器预览；Service Worker 需要 localhost 或 HTTPS。GitHub Pages 使用 `main / (root)`。

```sh
node --test tests/reading.test.mjs
```

测试覆盖旧数据迁移、教材分课、备份合并及幂等性、复习排期、翻译分段和内容完整性。另用浏览器检查阅读、查词、在线翻译、EPUB 导入、三种复习及课程题型和手机布局。
