# English Studio

手机测试：https://aeneas007.github.io/english-studio/

无需账号。阅读数据、单词和自定义文章存储在当前浏览器，可导出 JSON 备份。首次在线打开后，页面和内置故事可离线使用；英语朗读是否离线可用取决于设备语音包。

## 阅读功能

- 新概念英语 1–4 册学习入口，可导入自己的 UTF-8 TXT 教材；未内置原版课文或音频。
- KJV 英文圣经常用 66 卷全文，1,189 章 / 31,102 节，按卷加载并缓存，文本来源和权利说明见 bible/SOURCE.md。
- EWA 官方在线阅读功能说明及官网入口。未接入其书库、账号或实时翻译接口。
- 6 篇原创 A1/A2/B1 分级故事，18 章，中英逐句对照。
- 搜索、难度/类型筛选、收藏、继续阅读和已读完书架。
- 点词查义、发音、上下文例句、编辑释义并加入复习单词本。
- 逐句朗读、暂停、停止、从任意句开始、语速和英语声音选择。
- 字号、米白/纯白/夜间背景、章节目录、断点续读。
- 句子书签与笔记，跳转回原文。
- TXT/粘贴导入、分章、添加自己的译文、备份导出/合并恢复、可恢复的文章移除。

## 范围

独立实现的英语阅读学习工具，与 EWA 无关联。内置故事为原创示例，词典是供内置故事使用的本地词义表；导入文章中的未知词需补充释义。译文是预先编写或用户添加的，不使用在线机器翻译。TTS 来自浏览器，不是原版真人有声书。没有云端账号或同步。

所有发布文件都在仓库根目录，GitHub Pages 使用 main / (root)。
