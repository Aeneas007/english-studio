# 听读与锁屏播放

阅读页有两种播放方式，均无需账号或语音订阅。

## 普通朗读

点击播放或句旁的播放按钮，使用设备现有英语声音。点词查义会暂时暂停，关闭词卡后继续；手动暂停后查词，不会自行恢复。

有可靠词边界的设备按原听点续播；没有逐词回调时，同一句的点击位置可用于接读。词卡上的“从这个词听”会明确从点选文字起播。普通设备朗读仍受浏览器后台运行限制。

## 锁屏听书

1. 在阅读页点击“锁屏听书”。
2. 选择美式女声 Heart 或英式女声 Emma，以及当前章节或当前及后两章。
3. 点击准备音频。首次约下载106MB离线模型、音色和运行组件；重复使用读取本机缓存。文字只在手机上处理。
4. 准备时保持页面在前台；浏览器允许时会暂时保持屏幕唤醒，完成或取消后释放。准备完成后点击播放，再返回桌面、切换应用或锁屏。
5. 可以使用锁屏、通知栏或耳机的播放/暂停控制。听读速度随阅读设置保存，查词后按音频时间继续。

听书只播放已准备范围，不依赖锁屏后继续推理或逐句启动下一个音频文件。选定范围合成为一份连续WAV音频，章节之间也不需要重新启动文件。生成较长章节需要等待，单次范围超过45,000字符时界面会提示缩小范围，避免占用过多内存。

模型采用免费本机WASM推理；生成速度可能慢于播放速度。当前手机实测六句生成约需1分钟，音频约16秒，这说明准备等待是当前实现的实际限制。

## 离线与保存

模型、所选音色、运行组件全部缓存后，可以断网生成其他文字的语音。另一种音色也需要先完整下载。已准备音频保存在本机IndexedDB；再次打开相同正文和音色，可直接继续播放。

清理站点数据会删除本机模型和音频。学习记录JSON备份保留阅读位置与偏好，不打包大型模型或音频；换手机后需要重新准备。听书设置可以删除当前这份音频。连续多章听到后续章节时，重新打开听书设置会显示“继续上次听书”，沿用原来的整份音频。

## 版本与重建

模型与声音固定到同一版本，避免升级时混用文件；缓存升级保留学习数据和模型。组件清单与许可证在 [NOTICE](../studio/vendor/offline-voice/NOTICE.txt)。

重建运行组件需要 Node.js，并在独立依赖目录安装以下精确版本：kokoro-js@1.2.1、@huggingface/transformers@3.5.1、phonemizer@1.2.1、onnxruntime-web@1.22.0-dev.20250409-89f8206ba4，以及esbuild@0.25.5。之后运行：

```sh
node scripts/build-offline-voice.mjs /absolute/path/to/node_modules
```

## 验证范围

2026-10-21 已在连接的 Android 17 / Chrome 155 实测：普通朗读点词后接读剩余文字、手动暂停不误恢复；本机生成六句连续音频，查词发音后按原音频时间恢复，以及断网播放已准备的音频。另在手机 Wi-Fi 与移动数据均关闭、模型 Worker 重新启动后，成功生成两句新文字，得到4.13秒音频，约耗时10秒；测试后恢复原网络状态。还验证了0.85倍速保持、三章音频进入第二章后的地址与阅读记录同步、刷新后按原时间续听，以及离开阅读后释放旧音频。

使用同一生产播放模块，另将上述本机生成的真实语音拼接为981秒连续WAV做播放压力测试：返回桌面后继续15秒；断开调试连接锁屏300秒，播放时间从15.99秒推进到316.33秒，没有中断；锁屏硬件媒体键暂停在316.51秒，并从该点继续。该测试验证连续文件播放，不代表已由模型生成一整本书，也不等同于所有手机、浏览器或省电模式均兼容。
