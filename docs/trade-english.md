# 澳洲职业现场英语

课程围绕澳洲 HVAC、电工、水工和建筑工的日常沟通独立编写。每个工种6课，共24课、192句双语对话、96项术语讲解和120道练习（72道场景理解、48道听音理解）。这些是英语沟通练习；具体工作安排和授权应按岗位培训及现场要求确认。

## 学习路线

| 路线 | 六个场景 |
|---|---|
| HVAC 暖通空调 | 预约到场、症状描述、设备与风口位置、许可与交接确认、报价与零件等待、客户交付 |
| 电工现场英语 | 每日任务、图纸与位置、配电装置名称、请求隔离确认、破损设备上报、完工记录 |
| 水工与管道英语 | 上门接洽、漏水和排水描述、停水沟通、配件订购与尺寸复述、粗装与安装协调、交付待办 |
| 建筑工地英语 | 报到与入场说明、任务范围与图纸版本、材料送货、搬运协作与通道确认、听清口语安排、收工交接 |

课程页可进入四个工种，也可从书架的“职业英语”打开对话读本。每课先阅读或听读完整对话，再查看术语和澳洲用词说明，做五题练习，最后尝试角色扮演。术语可保存到单词本，并保留课程来源及例句；角色扮演草稿自动保存在本浏览器，随全部备份导出。

发音使用设备英语语音，声音和口音取决于设备提供的语音包，可在阅读设置中选择。口语如 air con、arvo、smoko 与正式用词的区别在课内说明；报时间、数量和尺寸时，示例会要求具体复述确认。
