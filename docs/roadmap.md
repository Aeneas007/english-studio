# 项目现状与未来计划

English Studio 希望让英文阅读、听力练习和词汇积累自然衔接，让每一次阅读都能留下可回顾的收获。项目采用本地保存、无需账号的方式，优先完善手机上的日常学习体验。

当前版本为 4.2，更新于 2026-10-17。本版扩充完整原著和四册原创配套学习，连接阅读、讲解、听力、练习与输出草稿。

## 当前功能

| 方向 | 已支持的能力 |
|---|---|
| 阅读书架 | 搜索、级别筛选、收藏、继续阅读和已读书架 |
| 阅读体验 | 按视口分页、横滑翻页、进度定位、句子与字符偏移续读、章节目录、字号、行距、三种主题、书签和笔记 |
| 英汉词典 | 759,373 条词条、贴近原文的点词卡、音标、英文释义、常见词形与原形查询 |
| 翻译辅助 | 原文旁的整句译文气泡、双语阅读、可选短语与整句在线翻译，结果保存在本地 |
| 听读练习 | 独立听读模式、逐句定位、句子跟随、变速、声音选择和睡眠定时；查词暂停、关闭词卡恢复，设备支持时逐词高亮 |
| 阅读内练习 | 每组最多 5 个词，配对与释义选择、成绩与词汇回顾，完成后回到阅读位置；不改变长期复习排期 |
| 词汇复习 | 原文例句、回到原文、释义选择、听音辨词、拼写回忆与复习排期 |
| 阅读内容 | 6 篇原创短篇、12 本完整英文原著（约 123 万词）、KJV 英文圣经 66 卷 |
| 个人教材 | 新概念四册 32 个原创配套单元、96 道语法理解题与 64 道听力题、本地输出草稿；个人教材 TXT / 未加密 EPUB 按课导入 |
| 情境课程 | 4 个生活场景、24 句表达，包含理解、听力和拼句练习 |
| 数据管理 | 本地统计、旧记录迁移、备份合并恢复、单词 CSV 导出和离线缓存 |

## 展望未来

以下是后续改进方向，尚未作为已上线功能提供：

- 丰富分级读物与学习主题，让不同阶段的学习者更容易找到合适内容。
- 增加词义与原文语境的关联，提高词义消歧、长句翻译和短语学习体验。
- 扩充听力材料，探索更自然的音频与字幕练习。
- 将情境课程组织成更连续的学习路径，增加练习变化与阶段回顾。
- 改进个人教材导入、目录识别和长篇阅读体验。
- 扩大实体手机验证范围，继续检查朗读、布局、后台播放、缓存更新与离线使用表现。

## 使用说明

四册配套内容独立原创，原版教材正文可另行导入自己的 TXT / EPUB；朗读使用设备语音，原版音频不内置。在线翻译默认关闭，开启后仅发送请求翻译的文本；免费服务可能限额、不可用或翻译不准确。朗读效果和逐词高亮取决于设备提供的语音能力。当前支持 TXT 和未加密 EPUB，PDF 暂不直接解析；新概念教材需导入自己的文件。

学习记录保存在当前浏览器中，更换设备或清理浏览器数据不会自动同步。请定期导出备份。内容来源与许可证见仓库 README、content/SOURCE.md、bible/SOURCE.md 和 lexicon/LICENSE.txt。
